# TypeScript reference

`schema/typescript` projects schemas to a TypeScript module of Effect Schema
values and the types they decode to, so a frontend reads what a Go program
serves from the same descriptions the program dispatches with.

```go
module, err := typescript.Module("Code generated by apigen. DO NOT EDIT.",
    api.FilmSchema.Structure(), api.PageSchema.Structure())
```

```ts
import { Schema } from "effect";

export const Film = Schema.Struct({
  film: Schema.Number,
  title: Schema.String,
  poster: Schema.optionalKey(Schema.String),
});
export type Film = typeof Film.Type;
```

## What each shape becomes

| Shape | TypeScript |
|---|---|
| text, bytes, timestamp | `Schema.String` — what JSON carries them as |
| integer, number | `Schema.Number` |
| boolean | `Schema.Boolean` |
| object | `Schema.Struct({...})`; an optional field is `Schema.optionalKey` |
| list | `Schema.Array(...)` |
| map | `Schema.Record(Schema.String, ...)` |
| nullable | `Schema.NullOr(...)` |
| union told apart by a field | `Schema.Union([...])` of structs carrying the field as a `Schema.Literal` |
| union wrapped in its variant's name | `Schema.Union([...])` of single-member structs |

## Named shapes are components

Every named object and union reachable from the roots becomes an exported value
and an exported type, declared once and in an order in which each is declared
before it is used. A name's qualifier is dropped and the rest is written in
PascalCase, as TypeScript names a type: `catalog.Film` is `Film` and `card_row`
is `CardRow`. Member names are the wire's and are left exactly as they are. Two
different shapes with one name are refused rather than one silently replacing
the other.

A recursive shape is suspended where it refers to itself, and its type is
written out and the value annotated with it, because TypeScript cannot infer a
type through a value that refers to itself:

```ts
export type Node = { readonly label: string; readonly children: ReadonlyArray<Node>; };
export const Node: Schema.Codec<Node> = Schema.Struct({
  label: Schema.String,
  children: Schema.Array(Schema.suspend((): Schema.Codec<Node> => Node)),
});
```

## What it deliberately leaves out

Constraints and formats. The projection describes the wire shape, and a value's
rules are the server's to enforce: a frontend that checked them again would only
disagree with the server about a rule it does not own. What the frontend does
check, strictly, is the shape — a field the server renames is a type error in
the frontend's build and a decode failure with a path in it at run time, never
an `undefined` on a page.
